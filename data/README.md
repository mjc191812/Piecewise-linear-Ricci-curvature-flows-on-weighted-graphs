# Data

The results reported in Table 8 were obtained on the three original, non-updated datasets `karate.gexf`, `football.gexf`, and `facebook.gexf`. These source datasets are from Ni, C.-C., Lin, Y.-Y., Luo, F. and Gao, J., "Community Detection on Networks with Ricci Flow", Scientific Reports 9, 9984 (2019).

The directories `moreno_health/`, `moreno_train/`, and `unicodelang/` contain supplementary experiment datasets. Their original README and metadata files are retained in each directory.
